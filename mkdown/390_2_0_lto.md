# 390 — LTO / Link-time optimization

La opción `-flto` selecciona optimización de programa completo para EXE, LIB y DLL. El generador
mantiene todas las funciones y datos del proyecto en un único módulo LLVM, ejecuta el pipeline
canónico de optimización una sola vez y sólo después emite el objeto nativo. Esto permite inlining,
propagación de constantes y eliminación de código entre las unidades que la compilación paralela
normal separaría. / `-flto` selects whole-program optimization for EXE, LIB, and DLL outputs. The
generator keeps all project functions and data in one LLVM module, runs the canonical optimization
pipeline once, and emits the native object only afterwards.

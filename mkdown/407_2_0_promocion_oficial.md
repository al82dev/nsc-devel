# 407 — Promoción oficial a NativeSharp 2.0 / Official NativeSharp 2.0 promotion

## Español

El compilador y el lenguaje pasan a `2.0.0`; la identidad visible estable es
`2.0.0+build.<UTC>.<id>` y el stage interno es 70. La ventana real de productores NSMETA se mueve a
1.0.1/2.0.0. `NativeSharp2Promotion.act` (`NSPROMOTION 1`) registra la decisión oficial y enlaza
todas las autoridades del cierre.

La documentación `docs/2.0` pasa a ser la edición vigente. El baseline completo de cierre se
ejecuta después de este cambio para medir exactamente el binario promovido.

## English

The compiler and language become `2.0.0`; the stable visible identity is
`2.0.0+build.<UTC>.<id>` and the internal stage is 70. The real NSMETA producer window moves to
1.0.1/2.0.0. `NativeSharp2Promotion.act` (`NSPROMOTION 1`) records the official decision and binds
every closure authority.

The `docs/2.0` tree becomes the current edition. The final complete baseline runs after this change
so it measures the exact promoted binary.

# 403 — Migración 1.0.1 a 2.0 / Migration from 1.0.1 to 2.0

## Español

La migración dejó de ser una nota pendiente del baseline. El compilador genera e instala
`NativeSharp2Migration.guide` (`NSMIGRATION-GUIDE 1`), un procedimiento canónico ligado al ledger
de rupturas. La guía fija los extremos 1.0.1 y 2.0.0, los contratos preservados, los cuatro pasos de
migración, el diagnóstico de enlace y la acción exacta para hosts estáticos.

`docs/2.0/MIGRATION_FROM_1_0_1.md` ofrece la misma decisión como documentación de producto. El
verificador de instalación exige ambos artefactos y el baseline de migración referencia ya sus
formatos reales, no marcadores `required`.

## English

Migration is no longer a pending baseline note. The compiler generates and installs
`NativeSharp2Migration.guide` (`NSMIGRATION-GUIDE 1`), a canonical procedure bound to the breaking
ledger. It fixes the 1.0.1 and 2.0.0 endpoints, preserved contracts, four migration steps, the link
diagnostic, and the exact static-host action.

`docs/2.0/MIGRATION_FROM_1_0_1.md` publishes the same decision as product documentation. The
installation verifier requires both artifacts, and the migration baseline now references their
real formats instead of `required` placeholders.

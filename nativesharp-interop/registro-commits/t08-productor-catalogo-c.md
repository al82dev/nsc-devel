# Conexión preparada del catálogo C al productor

Después de reunir la superficie y dependencias, el productor consulta el
proveedor opcional y asigna el minor 1.42 si hay catálogo. Sin proveedor se
mantiene el resultado anterior. El driver aún no instala el proveedor y el
escritor público continúa rechazando 1.42 hasta completar el consumidor.

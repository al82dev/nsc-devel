# Tanda 08: adaptador del inventario al frontend

`provideCppTypeAliases` transforma el inventario conservando proyecto,
referencia, triple y declaración. Un fallo conserva el proyecto y el índice de
referencia en el mensaje; no entrega un resultado parcial. Todavía no resuelve
visibilidad, equivalencia o uso de los aliases. Validación agrupada pendiente.

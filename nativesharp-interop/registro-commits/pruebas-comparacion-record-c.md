# Controles de comparación de records C

La suite comprueba registros completos de módulos distintos, variaciones de
campo y destino, USR ausente y preservación del resultado ante datos inválidos.
Son controles de contrato: una coincidencia no activa interoperabilidad ni
demuestra la identidad nominal de las declaraciones. La suite construyó y pasó
con código 0 después de `01155c33e`; la tanda completa sigue sin validar.

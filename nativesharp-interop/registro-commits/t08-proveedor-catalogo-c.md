# Proveedor opcional de catálogo C

El frontend admite configurar antes de compilar un proveedor que reciba el
modelo de metadata y devuelva un catálogo. Si el proveedor falla, la salida
previa permanece intacta; sin proveedor, se obtiene un catálogo vacío. No se
instala desde el driver ni activa el formato nuevo. Pendiente de validación.

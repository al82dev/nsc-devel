# Tanda 08: proyecto preparado de record C por puntero

El fixture declara un struct C y funciones para obtenerlo y leerlo por puntero.
El consumidor NativeSharp escribe el campo y devuelve cero si la biblioteca C
observa el mismo valor. Aún no se ha compilado ni ejecutado. No prueba paso por
valor ni otros layouts; se incorporará a la validación agrupada de la tanda.

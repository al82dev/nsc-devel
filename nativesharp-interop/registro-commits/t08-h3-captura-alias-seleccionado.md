# T08 H3: captura preparada de alias seleccionado

Se prepara una captura interna que compara la observacion elegida con el inventario por proyecto, referencia, destino, nombre, USR y tipo subyacente. Rechaza observaciones ausentes o ambiguas sin alterar la salida. El llamador debe acreditar que la referencia procede de una sesion C y que el alias fue seleccionado por resolucion semantica: el inventario por si solo no demuestra ninguna de las dos cosas.

Se prepararon controles sinteticos para coincidencia, referencia equivocada y duplicados. Quedan pendientes la construccion y ejecucion agrupadas, la conexion con resolucion real, el transporte publicado y las pruebas de bibliotecas. No se modifica NSMETA ni se cierra H3 o la tanda 8.

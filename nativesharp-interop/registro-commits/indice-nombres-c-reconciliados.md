# Índice de nombres C reconciliados

El índice asigna un ordinal canónico cuando existe un destino previamente
validado y visible desde el módulo consumidor. Las búsquedas de nombres simples,
calificados y de identidad deduplican esos ordinales. Aún faltan la expansión de
alias, observación y proyección de firmas; el comportamiento completo espera
validación agrupada y no se considera cerrado.

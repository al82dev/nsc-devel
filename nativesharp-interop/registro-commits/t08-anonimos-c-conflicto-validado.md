# Validación del conflicto C anónimo

El fixture completo terminó con código 0. Antes de los casos compatibles, el
control negativo verificó que NSC rechazara las dos observaciones incompatibles
de `CConflict`, con el diagnóstico de definición conflictiva o no verificada.
Luego pasaron los casos directo, dos sesiones equivalentes, Shared y Metadata
en O0–O3. El control no demuestra todas las formas posibles de conflicto.

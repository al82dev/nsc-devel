# Casos del modelo para alineación importada

Se preparan dos observaciones sintéticas: el modelo rechaza una alineación 3,
que no es potencia de dos, y conserva offset 9 con alineación 1 en un campo de
cuatro bytes. Son pruebas del modelo interno, no habilitan la importación real
de structs empaquetados y aún están pendientes de ejecución agrupada.

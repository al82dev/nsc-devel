# Tanda 08: declaraciones adelantadas de enum C

El catálogo concilia el destino y la identidad conocida de todas las observaciones,
incluidas declaraciones incompletas, y utiliza una definición completa para el
layout y los valores. Si solo existe una declaración adelantada, el catálogo
sigue rechazándola; identidades o destinos contradictorios también se rechazan.

El cambio está pendiente de la validación agrupada de la tanda 08. No habilita
por sí mismo la publicación del catálogo ni demuestra interoperabilidad completa.

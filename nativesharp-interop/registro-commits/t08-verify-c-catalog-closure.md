# Tanda 08: cierre de referencias de tipos C

La verificación de firmas incorpora tipos locales desde el catálogo C después de
validar sus bytes y su destino. Exige una dependencia externa para identidades
de otros módulos y rechaza colisiones con declaraciones o especializaciones.

El formato 1.42 sigue deshabilitado. Esta preparación no está construida ni
validada y no demuestra publicación ni consumo de una NSMETA real.

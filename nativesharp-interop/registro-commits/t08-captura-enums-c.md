# Captura de enumeraciones C requeridas

Se recopilan enums nombrados requeridos por identidad y proyecto, conservando la
declaración, tipo subyacente y constantes. Las observaciones deben coincidir en
destino, dimensiones, tipos y valores; los USR conocidos se reconcilian. Un
enum ausente o incompatible impide devolver un catálogo parcial. Pendiente de
codec, reconstrucción y validación agrupada.

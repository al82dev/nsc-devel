# Tanda 08: contrato de alias para el frontend

`CppImportedTypeAlias` conserva la declaración de Clang con el ordinal y archivo
del proyecto, la referencia y el triple. Es una observación poseída, no una
declaración ya resuelta. Los consumidores deben comprobar visibilidad y
compatibilidad entre observaciones antes de tratar el nombre como un alias.

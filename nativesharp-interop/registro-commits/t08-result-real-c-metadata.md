# Resultado: biblioteca y consumidor con tipo C

El NSC construido incrementalmente emitió la biblioteca del fixture con un tipo
C en la API; el consumidor separado enlazó y ejecutó con código 0 en O0. La
suite de sesión pasó después de corregir la versión explícita del fixture 1.41.
Se mantuvieron advertencias de inicializadores; el cierre de la tanda y las
variantes adicionales siguen pendientes.

# Tanda 05: propiedad compartida y sesión real

La prueba mantiene una compilación y una sesión real de Clang mediante un
propietario compartido, comprueba que siguen disponibles y después libera el
último propietario. Es una prueba de propiedad, no de integración del servicio de
lenguaje con referencias C++. Pendiente de validación agrupada.

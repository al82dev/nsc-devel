# Tanda 08: pruebas preparadas de typedef a record

La sesión C declara alias del record `Pair` y de un puntero a `const Pair`. La
prueba compara identidad, profundidad de puntero y calificador preservado. No
comprueba todavía generación de código ni lifetime; su ejecución corresponde a
la validación agrupada de la tanda.

# Tanda 07: validación previa de opciones de referencia

Antes de abrir cualquiera de las sesiones de un proyecto se comprueban la
cancelación, el lenguaje, el estándar no vacío, la ruta del header y las
opciones estructurales de includes y macros de todas sus referencias. Clang
sigue validando el significado de cada estándar y el acceso real a los archivos;
esta comprobación no pretende sustituirlo. Pendiente de validación agrupada.

# Tanda 08: plegado de enumeradores C ya enlazados

El resolvedor del cuerpo entrega al evaluador el par de bits y tipo de un
enumerador C vinculado como estado de namespace. Evita interpretar el ordinal
de ese estado como ordinal de miembro de clase. El evaluador conserva sus reglas
de normalización; falta conectar el proveedor y ejecutar las pruebas de casos
constantes en la validación agrupada.

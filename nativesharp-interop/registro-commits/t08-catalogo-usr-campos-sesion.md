# Tanda 8: identidad de campos C en el catálogo precompilado

La prueba compara los USR no vacíos de los tres campos proyectados desde una sesión Clang real con los campos reconstruidos a partir del catálogo codificado y decodificado. Identifica cada campo por propietario y nombre. La construcción incremental de `nsc_cpp_session_tests` terminó con código 0 y 32 advertencias de inicializadores; la suite terminó con código 0 en A:.

Esto no demuestra por sí solo escritura y lectura de un archivo NSMETA ni persistencia de funciones, globales y aliases. No cierra T08-002 ni altera el formato de metadata.

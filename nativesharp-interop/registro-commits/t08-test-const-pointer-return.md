# Pruebas de resultados C de puntero a const

El fixture prepara lectura de resultados const a escalar y struct, paso del
resultado a una función const, y rechazos de escritura, conversión mutable y
llamada mutable. Las causas negativas se comprueban de forma específica.
Pendiente de validación agrupada; no cubre punteros volatile ni niveles anidados.

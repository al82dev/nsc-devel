# Controles del catálogo de formato flotante

Se prepararon controles de ida y vuelta del indicador IEEE, rechazo de un
indicador inválido y comparación insuficiente cuando falta evidencia. El
fixture anterior mantiene controles de compatibilidad y truncamiento. Falta
construir y ejecutar la suite; otros casos anidados y el fingerprint siguen
pendientes de cobertura específica.

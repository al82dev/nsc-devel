# Pruebas de puntero global C a struct const

El proyecto prepara la lectura del campo por el puntero con contraste C y
rechazos de escritura, dirección de campo y conversión a puntero mutable. El
caso de puntero mutable permanece en el mismo proyecto. Pendiente de validación
agrupada; los punteros a volatile y niveles adicionales siguen pendientes.

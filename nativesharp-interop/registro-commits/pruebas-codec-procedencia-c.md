# Controles preparados del codec de procedencia C

Se ejercitan la conservación de una ruta Unicode y su huella, la estabilidad
del codec anterior, el rechazo de datos truncados y de hashes inválidos, y la
preservación de salidas ante error. El formato nuevo aún no está conectado a
NSMETA. La construcción incremental y la suite de sesión pasaron con código 0;
no constituyen la validación completa de la tanda.

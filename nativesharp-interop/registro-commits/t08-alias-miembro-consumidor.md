# Consumidor de alias C de miembro publicado

El control compila un consumidor que usa `NAlias` y `NMood` desde la metadata
del productor. El encabezado C se oculta durante cada compilación del consumidor
y se restaura antes de devolver el resultado. Se prepara la ejecución O0–O3;
todavía no está validada y la prueba no acredita alias fuera de firmas.

# Fixture de miembros anónimos C en bibliotecas

El fixture contrasta el mismo record C con union y struct anónimos en consumo
directo, biblioteca con encabezado y biblioteca solo con metadata, de O0 a O3.
Las escrituras de NativeSharp se contrastan con una función C de la biblioteca.

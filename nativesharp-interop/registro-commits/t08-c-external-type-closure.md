# Tanda 08: cierre externo de tipos C

El cierre de LibraryReference puede reconocer tipos record y enum C del catálogo
validado del módulo propietario. Un catálogo inválido, sin el tipo o perteneciente
a otro módulo no satisface la referencia. El formato 1.42 permanece deshabilitado.

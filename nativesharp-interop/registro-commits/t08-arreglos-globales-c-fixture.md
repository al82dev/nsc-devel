# Tanda 08: fixture de arreglos globales C

- El proyecto mixto prepara un arreglo `int[3]` y una matriz `int[2][3]` definidos en C. NativeSharp escribe y lee elementos; una función C verifica los mismos cambios.
- Estado: pendiente de validación agrupada. No demuestra arreglos calificados, incompletos ni de tipos compuestos.

# Prueba de union C por valor

Se preparó un consumidor independiente que recibe y pasa a C unions de 4 y
12 bytes. El caso apunta a las formas directa e indirecta del ABI Windows x64.
La matriz O0–O3 compiló, enlazó y ejecutó con código 0. Es evidencia para
estos dos layouts, no acredita todos los tipos de union ni todos los ABI.

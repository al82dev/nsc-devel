# Verificación inicial del catálogo C en metadata

El modelo de metadata verifica que el catálogo sea legible, no vacío y tenga
codificación estable; comprueba además que todos sus triples coincidan con el
destino de la biblioteca. La comprobación no valida todavía referencias entre
tipos ni habilita NSMETA 1.42. Pendiente de pruebas agrupadas.

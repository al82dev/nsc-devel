# Tanda 08: selección y campos de records en sesiones C

Para grafos con sesiones C sin sesiones C++, el controlador prepara los
proveedores de candidatos, selección por uso y campos, junto con su lowering.
La configuración existente para sesiones C++ permanece independiente. Esta
conexión aún no demuestra el ABI ni el comportamiento ejecutable y debe pasar
la validación agrupada de la tanda.

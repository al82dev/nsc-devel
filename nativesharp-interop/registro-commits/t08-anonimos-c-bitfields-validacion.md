# Validación inicial de campos de bits C anónimos

El fixture ampliado terminó con código 0 en O0–O3 para consumo directo, Shared
y Metadata. Las escrituras de campos de bits en agregados anónimos naturales y
empaquetados fueron comprobadas por C; las escrituras posteriores de C fueron
leídas por NativeSharp.

La prueba cubre las anchuras y valores concretos del fixture, no todos los tipos,
órdenes volátiles ni combinaciones de empaquetado. La validación completa de la
tanda 8 permanece pendiente.

# Tanda 08: representación de tipos de función

El modelo de tipos puede conservar resultado, parámetros, convención de llamada,
presencia de prototipo y variadicidad para un tipo función. Un puntero puede
referirlo mediante su elemento existente. Es información estructural, no una
afirmación de soporte de llamadas indirectas ni de ABI. Pendiente de validación.

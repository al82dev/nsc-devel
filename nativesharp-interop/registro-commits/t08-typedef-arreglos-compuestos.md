# Tanda 08: typedefs de arreglos de tipos importados

Se prepara la expansion de arreglos C de tamano fijo cuyos elementos sean enums
o records importados, conservando identidad y dimensiones. Las formas cuyo
calificador o limite no se representa se diagnostican. Pendiente la validacion
agrupada y la comprobacion de seleccion de dependencias y acceso efectivo.

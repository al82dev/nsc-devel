# Procedencia transitoria en snapshot C

El snapshot conserva la procedencia del buffer de la definición si todas las
definiciones completas observadas coinciden. Ante ausencia o discrepancia la
descarta, sin extrapolar identidad desde el nombre o la ruta. El formato 1.42
permanece intacto y este dato aún no se serializa en bibliotecas. Los controles
de acuerdo y discrepancia pasaron en la suite de sesión con código 0.

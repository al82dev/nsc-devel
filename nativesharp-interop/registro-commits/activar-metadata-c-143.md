# Activación de metadata C 1.43

La versión 1.43 del productor usa la envoltura de procedencia para catálogos C;
la escritura explícita anterior conserva el formato histórico. La procedencia
no equivale a identidad nominal. Falta asegurar que no cambie la huella ABI y
probar conjuntamente lectura, escritura y consumidor antes de considerarla lista.

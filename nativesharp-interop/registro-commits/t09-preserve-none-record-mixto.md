# T09-003: record compacto por valor con escalar preserve_none

Para una funcion C++ de retorno escalar y un record trivial de cuatro bytes por valor, se valida el plan de Clang y su portador `i32`. La identidad y layout del record se concilian con la sesion o catalogo importado; el emisor vuelve a comprobar que el portador corresponde a un record de cuatro bytes y alineacion cuatro. Se transporta el plan por el contrato NSMeta vigente. Esta ruta no generaliza otros tamaños, mas de un record por valor ni retornos de record.

# Preservación del catálogo C en el modelo de metadata

El modelo incorpora el catálogo codificado, la poda lo conserva y la fusión
exige concordancia entre fragmentos que lo aportan. Escribir o verificar una
versión anterior a 1.42 con el catálogo presente se rechaza. Todavía no se
habilita 1.42, no hay publicación ni lectura del catálogo en NSMETA y los
controles agrupados permanecen pendientes.

# Tanda 08: proveedor de typedef en el controlador

Cuando el grafo tiene sesiones C/C++, el controlador instala el proveedor que
captura los aliases antes del análisis de nombres. La ausencia de sesiones
mantiene el camino ordinario. Esto conecta el inventario, pero no certifica
que todas las formas de typedef sean utilizables; tipos compuestos y validación
agrupada permanecen pendientes.

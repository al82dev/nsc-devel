# Tanda 08: expansión inicial de typedef a puntero de función

La resolución de nombres convierte una firma C proyectable en el tipo de función
estructural existente de NSC, con convención de llamada, resultado, parámetros y
variadicidad. Los modificadores de uso aún no representados se rechazan. Esta
conexión no demuestra llamadas ejecutables; el driver y la validación agrupada
siguen pendientes.

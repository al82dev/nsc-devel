# T09-003: acceso a componentes de un campo vectorial C++

NSC captura un vector fijo de elementos escalares y proyecta sus componentes mediante una vista indexable de arreglo para campos de records C++ triviales, cuando el tamaño físico coincide exactamente con los componentes y se verifica el layout. Conserva el desplazamiento y la alineación físicos; el catálogo NSMeta vigente transporta el tipo y reconstruye la misma vista. Esto no implementa operaciones SIMD ni parámetros vectoriales generales.

En el fixture `pruebas-tanda-09-preserve-none-cpp-retorno-record-vector`, NativeSharp escribe y lee cuatro componentes, y C++ comprueba y copia el registro. La ruta directa y por puntero pasó estática y DLL con O0–O3: `A:/temp/nsc-t09-preserve-cpp-retorno-record-vector-vobbdfn8`. El productor y 16 consumidores precompilados, con y sin encabezado, pasaron: `A:/temp/nsc-t09-preserve-cpp-retorno-record-vector-precompilado-16tbwisb`. Las mismas matrices con componentes `int` pasaron en `A:/temp/nsc-t09-preserve-cpp-retorno-record-vector-6hrl4_y1` y `A:/temp/nsc-t09-preserve-cpp-retorno-record-vector-precompilado-7dzc5ukd`.

El control negativo de vector de tres componentes con relleno se conserva en la ruta viva y en el consumidor precompilado; no se acredita acceso a ese campo. Pasaron también las pruebas `nsc_cpp_abi_probe_tests`, `nsc_cpp_record_value_observation_tests` y `nsc_cpp_regcall_record_plan_tests` (`A:/temp/t09-scoped-enum-unit-tests.log`), además de la regresión C precompilada `A:/temp/nsc-t09-sysv-indirecta-record-pre-gc2k58pd` y la C++ variádica con enum `A:/temp/nsc-t09-cpp-variadica-sysv-enum-record-precompilado-_6kjm22c`.

Límite abierto: un record con vector de cuatro `double` y alineación 32 funciona en la muestra precompilada (`A:/temp/nsc-t09-preserve-cpp-retorno-record-vector-precompilado-1br8f60q`), pero la ruta viva falla al generar objeto por la interacción de alineación de pila y funclets de excepciones en LLVM (`A:/temp/nsc-t09-preserve-cpp-retorno-record-vector-u7qpbke9/estatica-O0-nsc.log`). Una transformación aislada del IR permite compilar el objeto (`A:/temp/t09-vector-align-probe.log`), pero no demuestra aún ejecución ni corrección del ABI. No se acredita esa ruta ni se cierra T09-003.

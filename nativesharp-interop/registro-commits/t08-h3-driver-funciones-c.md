# Tanda 8: conectar funciones C precompiladas al driver

Cuando hay un catálogo C precompilado, el driver configura el proveedor que
combina funciones vivas y restauradas. La prueba de biblioteca real pasó en O0
con los cambios conjuntos de publicación y verificación. Permanecen pendientes
las funciones internas, las declaraciones no proyectadas y las colisiones.

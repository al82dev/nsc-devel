# Contratos de puntero a matriz C

Se prepara comprobación de mutación desde C de una matriz NativeSharp y los
rechazos de matriz const o dimensiones incorrectas. Los controles requieren
errores de llamada concretos. Pendiente validar junto al caso de lectura.

La matriz agrupada pasó O0–O3 con `915a25d711461ecf`; ambos argumentos
incorrectos se rechazaron con el diagnóstico esperado y se alcanzó el marcador
final del script. No es validación de todos los tipos de arreglo.

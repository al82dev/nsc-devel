# Tanda 08: diagnóstico de record C/C++ incompleto

El inventario conserva si el grupo solo tiene declaraciones adelantadas. Cuando
se solicita un layout por valor, el diagnóstico distingue esa situación de un
layout que no se ha importado por otra causa. No se inventan dimensiones ni se
habilita almacenamiento por valor; falta ejecutar la validación agrupada.

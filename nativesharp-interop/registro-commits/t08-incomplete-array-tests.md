# Tanda 08: prueba de arreglos completos e incompletos

Se preparó una comprobación con `typedef int IncompleteArray[]` y
`typedef int FixedArray[7]`: debe conservarse el tipo de elemento en ambos,
sin tamaño ni cantidad para el incompleto, y con siete elementos para el fijo.
La prueba se ejecutará en la validación agrupada; no se anticipa su resultado.

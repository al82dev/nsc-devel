# T08-003: control de consumo de sidecars con objetos nativos

La matriz de inline C exige ahora sidecars para ambos productores en O1–O3 y
que el consumidor informe dos bibliotecas ThinLTO consumidas. En O0 comprueba
que no permanezca un sidecar de una compilación anterior. Conserva las pruebas
de funcionamiento y separación de estados; se registrará el resultado después
de activar y construir la integración completa.

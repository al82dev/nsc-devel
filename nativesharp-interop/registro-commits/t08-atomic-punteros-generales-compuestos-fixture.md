# T08-004: aritmética sobre punteros atómicos C

La prueba prepara avance por elemento de punteros atómicos a struct y bool.
La función C existente comprueba que los punteros apuntan a los segundos
elementos. El control C usa asignación, pues Clang rechaza el operador
compuesto aplicado directamente a un puntero atómico C. Pendiente de ejecución.

# USR en dependencias de record de una firma

El grupo de records conserva el USR conocido cuando no hay conflicto. Al
buscar una dependencia de firma, un USR conocido distinto se clasifica como no
proyectable en vez de vincularse solo por nombre. Si falta información se
conserva el comportamiento anterior y sigue siendo necesaria la comparación
de layout y estructura. Validación agrupada pendiente.

# T09-003: puntero a record C++ con preserve_none

Se valida el plan fisico de punteros a records C++ identificados. Antes de emitir una llamada directa se cotejan el tipo proyectado, USR y layout con el registro importado. Para un callback, la sesion viva verifica el registro de Clang y la ruta precompilada coteja identidad, layout, catalogo y alias; el emisor valida de nuevo la forma fisica. La conciliacion se limita a registros C++ completos y elegibles como valores triviales. El contrato NSMeta conserva sus campos existentes, sin versiones historicas.

La firma `int(float,Small*)` paso ocho controles Clang 23.1.0 O0-O3 en estatica y DLL (`A:/temp/nsc-t09-preserve-cpp-puntero-record-3zvmlol2`); NSC antes la rechazaba (`A:/temp/nsc-t09-preserve-cpp-puntero-record-u6e2z4r6`). Pasaron ocho comparaciones directas y por callback con modificacion del campo, retorno, simbolos, IR y plan HIR (`A:/temp/nsc-t09-preserve-cpp-puntero-record-8ozu9ibm`), y 16 consumidores precompilados con y sin encabezado (`A:/temp/nsc-t09-preserve-cpp-puntero-record-precompilado-9yl5exet`). Sin plan, la llamada indirecta se rechaza (`A:/temp/nsc-t09-preserve-none-recordptr-sin-plan-zbldqfu9`).

La prueba `nsc.cpp-interop.regcall-record-plan` paso para el plan real, ida y vuelta NSMeta y rechazo sin USR. La prueba negativa existente se conserva con un record por valor no cubierto (`A:/temp/nsc-t09-preserve-none-negativo-1us4jfiq`). Pasaron regresiones de puntero escalar precompilado (`A:/temp/nsc-t09-preserve-cpp-puntero-escalar-precompilado-9qm0l8mm`), retorno void (`A:/temp/nsc-t09-preserve-cpp-void-escalar-k7dj747f`) y callback de record de 44 bytes precompilado (`A:/temp/nsc-t09-preserve-cpp-record24-precompilado-rf8j6wja`). No se certifican registros incompletos, no triviales ni todas las combinaciones; T09-003 y la tanda nueve siguen abiertos.

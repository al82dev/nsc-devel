# Tanda 08: proyecto preparado de comparación de layout C

El consumidor compara `sizeof`, `alignof` y `offsetof` de un struct importado
con las respuestas de funciones compiladas por Clang desde el mismo header C.
Los códigos 1, 2 y 3 identifican la magnitud que difiere. Todavía no se ha
compilado ni ejecutado y el fixture no certifica otros tipos o configuraciones.

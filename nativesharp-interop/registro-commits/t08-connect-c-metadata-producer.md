# Tanda 08: productor del catálogo C

El driver configura el proveedor de metadata cuando hay sesiones C/C++ en el
proyecto. Solo se emite el catálogo si la API publicada requiere tipos C; los
orígenes no soportados se rechazan. La ruta requiere validación de extremo a
extremo y no acredita aún soporte de tipos C++ en metadata.

# Tanda 08: contrato de captura de aliases

Se define una instantánea propia para nombres de alias, tipo subyacente y
ubicación. La consulta es opcional para no atribuir capacidad a sesiones que no
la implementan. El contrato no afirma que NativeSharp ya pueda resolver el alias;
esa integración y la validación de la tanda permanecen pendientes.

# Union C con miembro flotante y struct anidado

Se prepararon casos de union de ocho bytes que contienen un double o un
struct. Comprueban retorno y paso por valor a C, y lectura y escritura del
struct anidado desde NativeSharp. La matriz agrupada compiló, enlazó y ejecutó
con código 0 en O0–O3 sobre Windows x64. Es evidencia para estos dos layouts;
no demuestra todos los miembros, calificadores ni arquitecturas.

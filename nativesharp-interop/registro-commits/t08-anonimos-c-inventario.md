# Agregados anónimos C en el inventario semántico

El inventario expande un record C con agregados anónimos en el propietario y los
tipos internos generados para cada carrier. Las identidades se crean dentro del
mismo proyecto y conservan el destino y modo volatile de la sesión de Clang.
Si la materialización detecta una ruta o nombre incompatible, el inventario informa
el error en lugar de publicar una observación incompleta.

Esta conexión aún requiere validación del enlace, metadata y ejecución en los tres
modos de consumo. La tanda 8 sigue abierta.

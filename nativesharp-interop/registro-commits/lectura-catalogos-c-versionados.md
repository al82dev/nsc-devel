# Lectura preparada del catálogo C versionado

Se añade una selección explícita entre el catálogo histórico y la envoltura
con procedencia, y se utiliza en la reconstrucción de tipos, miembros y fuentes
precompiladas. La deduplicación compara también la procedencia serializada para
no descartar diferencias. La escritura aún no está habilitada. Pendiente de
verificación de versión de metadata y validación agrupada.

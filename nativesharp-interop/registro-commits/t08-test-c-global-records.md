# Casos de globales C de struct

El proyecto mixto prepara acceso a un objeto global de struct, un puntero global
y un arreglo global de structs, y una función C comprueba las tres escrituras.
El nombre del struct no se usa en NativeSharp ni en las firmas llamadas: debe
seleccionarse a partir de los globales. El caso está preparado y aún no se ha
validado; no demuestra calificadores ni paso de agregados por valor.

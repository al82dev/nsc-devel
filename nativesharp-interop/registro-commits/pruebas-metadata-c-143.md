# Controles de metadata C 1.43

Se comprueba la conservación de la procedencia al escribir y leer metadata 1.43,
la compatibilidad de lectura con 1.42 y que la proyección ABI sea la misma para
el mismo contrato C con o sin procedencia. La suite pasó tras corregir los
controles antiguos del productor; la batería real sigue fallando en la variante
de encabezado compartido.

# Lectura efectiva de tipo C publicado

El productor expone una función que devuelve el puntero C y el consumidor lee
el campo y exige el valor 17 en ejecución. Se conserva el control de un campo
público NativeSharp que apunta al mismo tipo. La prueba sigue sin ejecutarse;
puede detenerse antes de llegar al consumidor por falta de metadatos.

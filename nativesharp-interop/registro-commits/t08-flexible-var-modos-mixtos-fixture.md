# T08-010/015: observación con referencias de modo distinto

El proyecto `VarVolatileMixed` abre dos sesiones del mismo encabezado con modos
Microsoft e ISO. Las funciones directas complementan el alias local en C y NS,
para contrastar ambos accesos bajo referencias coincidentes y divergentes.
La ejecución sigue pendiente y este cambio no establece la política del
compilador para una unidad NativeSharp.

# T08-004: proyeccion de global estatica C int

Se selecciona la instancia de una referencia C para el caso int de 32 bits
reproducido, con simbolo propio; varias instancias del mismo nombre se reportan
como ambiguas. Falta que el driver solicite la definicion y la validacion
agrupada. Esta proyeccion no acredita otros tipos ni TLS.

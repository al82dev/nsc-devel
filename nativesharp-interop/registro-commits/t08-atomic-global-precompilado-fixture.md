# T08: global C atómico precompilado y DLL

Se prepara un productor NativeSharp precompilado, un consumidor y una DLL
intermedia con su propio consumidor. Ambos se compilan con el header C oculto
y verifican lectura, incremento y lectura desde C en O0–O3. El fixture no se
ha ejecutado; no acredita la ruta ni modifica producción o NSLink.

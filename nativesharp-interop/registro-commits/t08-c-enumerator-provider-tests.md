# Tanda 08: prueba preparada del proveedor de enums C

La prueba prepara una sesión C real con `Choice = -3` y comprueba el estado
constante, y después añade otra referencia con `Choice = 5` para exigir un
error diferido por conflicto. Se ejecutará con la validación de la tanda; no
certifica todavía todos los ámbitos o las colisiones con variables.

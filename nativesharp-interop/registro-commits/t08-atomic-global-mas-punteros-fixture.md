# T08: diagnóstico de punteros atómicos globales a float y long C

Se prepara un fixture con globales atómicos no TLS a float, long y unsigned
long C. Comprueba que NativeSharp los importe, asigne y avance, y que C observe
los punteros resultantes. Aún no se ha ejecutado ni acredita soporte. No se
modifica producción o NSLink.

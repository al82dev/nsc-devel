# Prueba del cálculo de alineación de arreglo en campo

La suite prepara un árbol MIR sintético de una matriz con campo alineado a 2
y strides 12 y 4; espera alineación 2. Un segundo caso cambia el origen a un
local y exige que no se invente una alineación de campo. La prueba está
pendiente de ejecución y no habilita arreglos empaquetados.

# Layout de puntero a función

El proyector de campo expuso una identidad estructural de función que el
cálculo de layout no reconocía. Se usa el tamaño y alineación de puntero del
destino para esa identidad. NSC se construyó incrementalmente y los fixtures
de campo y global compilaron, enlazaron y ejecutaron en O0–O3. La validación
se limita a esos casos; las demás firmas y calificadores siguen abiertos.

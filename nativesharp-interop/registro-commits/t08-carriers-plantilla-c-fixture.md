# Fixture real de carriers y dependencia C de plantilla

El productor que publica records con agregados anónimos incorpora una plantilla
que devuelve un enumerador C anónimo. El consumidor la instancia mientras usa
esos records, con y sin encabezado, en O0–O3. Esto exige conservar carriers y
dependencias en la misma metadata.

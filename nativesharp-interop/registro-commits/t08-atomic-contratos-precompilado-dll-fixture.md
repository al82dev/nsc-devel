# T08-004: biblioteca con globales atómicas y DLL NativeSharp intermedia

La matriz prepara una DLL NativeSharp que enlaza el productor precompilado y
un consumidor independiente. Ambos se compilan con el encabezado C oculto;
se inspecciona el directorio TLS de la DLL y se ejecuta O0–O3. Pendiente de
validación.

# USR en grupos de records

T08-002/T08-010/T08-011: el agrupador marca conflicto si las declaraciones
conocidas del mismo nombre y proyecto tienen USR distintos. Un grupo sin ese
conflicto transporta el USR disponible al tipo importado. El USR no sustituye
las verificaciones de layout, ODR o comparación estructural. La validación de
los casos se agrupa con la tanda.

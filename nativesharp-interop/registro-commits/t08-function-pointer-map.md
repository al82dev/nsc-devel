# Tanda 08: proyección inicial de firmas C por puntero

Se añade una representación verificable para firmas con prototipo, puntero de
64 bits, convenciones conocidas y parámetros/resultados escalares que el modelo
puede expresar sin descartar calificadores. Las demás firmas permanecen sin
proyectar; esto no afirma que NSC ya pueda llamarlas. La construcción y las
pruebas se agrupan al final de la tanda y aún no se han ejecutado.

# Prueba de dirección de arreglo volatile

El proyecto comprueba el diagnóstico específico para las direcciones de un elemento
de arreglo y de matriz `volatile`. El caso positivo toma y lee la dirección de un
elemento de arreglo mutable, para detectar un rechazo excesivo. Los resultados se
recogerán al ejecutar la validación agrupada de la tanda 08.

# T09-003: layout fisico de retorno indirecto preserve_none

Se calcula de forma acotada el tamaño y alineacion de tipos fisicos escalares, arreglos y estructuras anidadas del `sret` para el data layout Win64 exacto observado en Clang 23.1.0. Se verifican tamaño, alineacion, atributos y posiciones antes de emitir; tipos no interpretables, vectores, profundidad excesiva y tamaños superiores al limite permanecen rechazados. La identidad y layout C++ se concilian con la sesion o catalogo; NSMeta conserva el contrato vigente. El calculo no certifica por si solo todas las disposiciones C++.

# Descenso de bitfields con ventana menor que el tipo

Se prepara el descenso para extraer y extender el signo desde la ventana de
almacenamiento hacia el tipo lógico, y para truncar o extender al escribir.
El ancho del campo se comprueba contra ambos. La batería y regresiones de los
bitfields propios de NativeSharp aún no se han construido ni ejecutado.

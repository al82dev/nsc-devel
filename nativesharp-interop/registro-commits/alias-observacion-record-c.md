# Alias y observación de records C reconciliados

Los alias de Clang pueden resolver al ordinal canónico cuando el destino fue
reconciliado y validado; la observación conserva el grupo Clang vinculado a ese
ordinal. No se usa el nombre por sí solo y se rechazan grupos múltiples hacia un
mismo ordinal. La proyección de llamadas y la validación agrupada aún faltan.

# Validación del destino C reconciliado

El índice de nombres verifica que cada destino exista una sola vez y que sea
un record C de otro módulo con igual nombre, tipo, triple, USR y dimensiones.
Rechaza cadenas, registros incompletos inconsistentes y destinos diferidos.
La comprobación protege el transporte interno; todavía no altera la resolución
de nombres ni reemplaza la comprobación de procedencia. Pendiente de controles
y validación agrupada.

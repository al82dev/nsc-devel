# Tanda 08: pruebas de captura de typedef

Se comprueban aliases C de un entero, un puntero, un record y un puntero a
constante, además de su ubicación y vida útil después del cierre. El doble de
sesión delegado transmite la nueva consulta. Estas pruebas no demuestran que el
frontend NativeSharp pueda resolver los nombres; se ejecutarán con la tanda.

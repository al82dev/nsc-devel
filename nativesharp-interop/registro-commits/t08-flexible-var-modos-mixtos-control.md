# T08-010/015: control de referencias mixtas

El diagnóstico compara los accesos directos y los realizados por alias para
cada modo y para un proyecto con ambas referencias, en O0–O3. Las referencias
mixtas se contrastan por separado con cada modo de Clang; no se declara que
ambos resultados puedan ser equivalentes a la vez. La ejecución queda pendiente.

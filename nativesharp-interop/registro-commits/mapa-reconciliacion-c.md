# Mapa de reconciliación C visible

La observación prepara correspondencias entre records de sesiones Clang y
catálogos precompilados visibles cuando coinciden origen y cierre de contratos.
No selecciona cuando la procedencia es insuficiente o hay más de un candidato.
El mapa aún no altera resolución ni conversiones; necesita controles y conexión
antes de atribuirle interoperabilidad. Pendiente de validación agrupada.

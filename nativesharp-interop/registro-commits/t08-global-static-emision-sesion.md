# T08-004: emision conjunta de globales C y funciones inline

La sesion acepta solicitudes de globales internas con nombres de enlace propios
y las exporta desde el mismo modulo que las funciones inline seleccionadas.
La integracion con el inventario y el driver, la construccion y la validacion
siguen pendientes; este cambio por si solo no habilita la importacion.

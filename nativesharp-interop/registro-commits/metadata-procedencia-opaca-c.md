# Versión de metadata para procedencia C incompleta

Se prepara NSMETA 1.45 para los catálogos que contienen procedencia de
declaraciones C incompletas. Los catálogos anteriores siguen seleccionando
sus mínimos 1.43 o 1.44; una versión anterior rechaza explícitamente la
extensión. Falta validar lectura, escritura, huellas, compatibilidad histórica
y conciliación del fixture completo antes de afirmar soporte.

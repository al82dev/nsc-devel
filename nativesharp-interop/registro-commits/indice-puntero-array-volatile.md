# Índice sobre puntero obtenido de arreglo C

El HIR reconoce la cadena de índices que carga un puntero a int volatile
directamente desde un global C y marca el acceso indexado al apuntado con el
modo MS. El recorrido tiene límite de profundidad y conserva el tratamiento
existente del slot. Otros orígenes permanecen pendientes; no está validado.

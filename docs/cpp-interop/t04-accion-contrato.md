# Contrato privado de acción y cancelación

Se declara la ejecución privada de la acción de sesión y una capa de sistema de
archivos con token de cancelación compartido. La propiedad del AST se entrega a
la sesión; el consumidor de diagnósticos es prestado por el llamador.

La acción y los puntos de cancelación se implementan y validan en esta tanda.

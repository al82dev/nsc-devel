# Validación de referencias binarias C++

La validación resuelve dependencias binarias registradas en metadatos, preserva
su orden para el enlazador y comprueba los nombres de DLL declarados frente a
las bibliotecas de importación que se pueden inspeccionar.

Este registro no certifica todos los formatos de bibliotecas ni todos los casos
de distribución; esas capacidades requieren las pruebas del conjunto.

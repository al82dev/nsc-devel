# Opciones del conductor para C y C++

Se incorporan las opciones `--cpp-clang-root` y `--cpp-system-include` al
análisis de argumentos, a los datos de invocación y a la ayuda en español e
inglés. Las rutas deben ser absolutas; las inclusiones de sistema deben existir.

Este commit registra cambios previamente acumulados. La comprobación de la
construcción y del comportamiento corresponde al conjunto, no al commit aislado.

# Carga de referencias C++ en proyectos

El cargador interpreta `CppLibraryReference`, valida sus atributos y opciones,
resuelve las rutas de encabezados, bibliotecas, DLL e inclusiones y guarda el
resultado en el modelo de proyecto. Rechaza entradas incompletas o inexistentes.

Este registro no demuestra que las bibliotecas importadas se puedan consumir;
esa capacidad depende de otros cambios y de su validación conjunta.

# Codificación de dependencias binarias C++

El formato 1.41 escribe y lee las rutas de archivo, tamaños y resúmenes de las
dependencias C++ y de sus archivos de ejecución. Versiones anteriores no pueden
representar esta colección y se rechaza una combinación incompatible.

La validación corresponde al conjunto de cambios, no al commit aislado.

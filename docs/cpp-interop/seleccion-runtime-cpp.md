# Selección de archivos de ejecución C++

El empaquetado reúne candidatas de referencias directas y metadatos, selecciona
las DLL requeridas por las importaciones y revisa conflictos de destino para
evitar sobrescribir archivos distintos.

La selección y su interacción con DLL transitivas se deben verificar como parte
del conjunto completo de empaquetado.

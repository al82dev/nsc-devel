# Opciones C++ en la construcción de proyectos

Los comandos de construcción aceptan las opciones de raíz de Clang e inclusiones
de sistema, validan sus rutas y las transmiten a la invocación anidada de NSC.
Se rechaza especificar inclusiones sin una raíz de Clang.

Este registro corresponde a cambios previamente acumulados; la validación es
conjunta con el conductor y la sesión de interoperabilidad.

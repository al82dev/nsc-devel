# Acta de promoción oficial de NativeSharp 2.0

NativeSharp `2.0.0` queda promovido al canal estable. La decisión conserva como autoridades
instaladas `NSBREAKING 1`, `NSMIGRATION-GUIDE 1`, `NSRCFREEZE 1`, `NSCOMPAT-MATRIX 1`,
`NSFINALBASELINE 1` y `NSPROMOTION 1`.

La ventana N-1/N es 1.0.1/2.0.0. Consulte la guía de migración para el único cambio binario
certificado: el enlace explícito de `NativeSharp.Runtime.Win32.lib` por hosts de bibliotecas
estáticas.

---

# Official NativeSharp 2.0 promotion act

NativeSharp `2.0.0` is promoted to the stable channel. The installed breaking ledger, migration
guide, RC freeze, final compatibility matrix, final baseline contract, and promotion act are the
canonical release authorities. The certified N-1/N window is 1.0.1/2.0.0.

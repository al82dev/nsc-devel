# NativeSharp: congelamiento histórico de candidata

La candidata de aquella campaña congelaba la superficie del lenguaje, compilador, formatos,
ABIs, runtime, linker, paquete y documentación de la revisión evaluada. Es evidencia histórica,
no certificación de los cambios actuales; la versión actual del producto es 1.0.

La política de la campaña no admitía características ni cambios de contrato después del
congelamiento; una corrección bloqueante exigía otra candidata y repetir la certificación. Aquella candidata registró Native
ABI 1.0, Runtime ABI 1.0, runtime symbol set 2 y MIR 1.11, junto con `NSBREAKING 1`,
`NSMIGRATION-GUIDE 1` y `NSCOMPAT-MATRIX 1`.

La candidata no era la promoción final. La campaña requería certificación y el baseline completo
de la tanda 16, seguidos por una decisión explícita de promoción.

# NativeSharp: historical release candidate freeze

The historical candidate froze the language, compiler, format, ABI, runtime, linker, package and
documentation surface of that revision. It does not certify later changes; the current product is
1.0. A release-blocking fix requires the appropriate recertification and an explicit promotion
decision.

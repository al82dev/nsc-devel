# Plan de pruebas — Host.LLVM

## 1. Alcance

Plan contractual de 64 contratos y 512 casos diseñados. No implementa ni ejecuta pruebas.

## 2. Fixtures futuros

- MIR mínimo genérico y físico construido por builders de test, no por blobs opacos;
- dobles con ownership explícito para contexto, módulo, target machine y filesystem temporal;
- LLVM 23 conocido para integración de C API, optimización, debug y object emission;
- oráculos estructurales de IR/COFF/metadata/cache que no comparen mensajes incidentales;
- ejecución parametrizada: un ejecutable unitario consolidado y fixtures `.ns` externos en la fase 2.

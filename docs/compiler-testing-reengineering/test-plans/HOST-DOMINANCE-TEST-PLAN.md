# Plan de pruebas — Host.Dominance

## 1. Alcance

Plan contractual de 32 contratos y 256 casos diseñados. No implementa ni ejecuta pruebas.

## 2. Fixtures futuros

- CFGs mínimos de línea, diamante, loops, múltiples joins, self-edge e inalcanzables;
- oráculo sencillo de conjuntos, independiente del builder de producción;
- corrupción dirigida de una sola relación por caso negativo;
- comparación byte a byte del dump y grafos profundos para algoritmos iterativos.

# Test plan contractual — Host.MIR

## Alcance

Plan documental derivado de 38 contratos observables. Diseña 304 matrices parametrizadas; no implementa ni ejecuta pruebas ni sustituye cobertura instrumental.

## Estrategia

- Unitarias para modelo, arena, opcodes, payloads, lookup y dump.
- De componente para lowering HIR→MIR, CFG, PreSsa/SSA y verificación opcode por opcode.
- Cada contrato incluye positivos, negativos, límites, variantes, determinismo y escala.

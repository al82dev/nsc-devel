# Test plan contractual — Host.HIR

## Alcance

Este plan se deriva de los 29 contratos observables de Host.HIR. Diseña 232 matrices parametrizadas; no implementa ni ejecuta pruebas y no sustituye cobertura instrumental futura.

## Estrategia

- Unitarias para arena, nodo, nombres, serializacion y predicados puros.
- De componente para lowering AST/Sema a HIR y para verificacion estructural y tipada.
- Fixtures aislados con objetos semanticos de lifetime controlado; nada depende de procesos externos.
- Cada contrato incluye positivos, negativos, limites, variantes, determinismo y escala.

# Plan de pruebas — Host.Passes

## 1. Alcance

Plan contractual de 56 contratos y 448 casos diseñados. No implementa ni ejecuta pruebas.

## 2. Fixtures futuros

- MIR SSA mínimo construido en arena, con funciones prototipo y definidas;
- grafos de línea, diamante, loop, ramas constantes, bloques inalcanzables y PHIs;
- oracles independientes de bits, uso-definición, reachability, predecessors y dominancia;
- passes falsos para controlar requisitos, cambios, errores, preservación y convergencia;
- comparación byte a byte de dumps y cadenas profundas para demostrar iteración acotada.

# Plan de pruebas — Host.SSA

## 1. Alcance

Este plan cubre los 42 contratos estables extraídos de los 14 archivos de Host.SSA. Diseña 336 casos
lógicos; no implementa ni ejecuta pruebas. Cada contrato posee siete casos `PR` y uno `NIGHTLY`.

## 2. Fixtures futuros

- constructores pequeños de MIR, CFG, dominancia y frontera de dominancia coherentes;
- corrupción dirigida de una sola relación por caso negativo;
- comparación estructural de MIR/metadata y dictamen independiente de `SsaVerifier`;
- captura byte a byte de `SsaDumper`;
- grafos profundos y anchos para confirmar recorrido iterativo sin depender del stack del proceso.

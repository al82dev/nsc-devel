# Test plan — Host.Frontend

## Alcance

Plan documental para 63 contratos y 504 casos lógicos parametrizables. No implementa ni ejecuta pruebas.
Cada contrato tiene ocho matrices obligatorias: nominal, clases válidas, vacío, bordes, inválidos,
dependencias fallidas, determinismo y escala adversarial. Cada matriz se materializará en Fase 2 con
todos los valores enumerados por `inputs`, `errors` y `observable_oracle` del contrato; no es un smoke.

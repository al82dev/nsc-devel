# Plan de pruebas — Host.Linker

## 1. Alcance

Plan contractual de 40 contratos y 320 casos diseñados. No implementa ni ejecuta pruebas.

## 2. Fixtures futuros

- builders binarios mínimos para COFF archive, PE32+ y PDB MSF 7 con mutaciones dirigidas;
- ejecutables hijo controlados para argumentos, cwd, logs y exit status;
- objetos COFF mínimos y dobles explícitos para cache, runtime y tool discovery;
- filesystem temporal por caso y oráculos estructurales independientes;
- integración NSLink separada de las unitarias deterministas.

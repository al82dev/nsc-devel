# Plan de pruebas — Host.Interop

## 1. Alcance

Plan contractual de 48 contratos y 384 casos diseñados. No implementa ni ejecuta pruebas.

## 2. Fixtures futuros

- builders mínimos de `LibraryMetadata` con cada catálogo y minor declarado;
- proyectos NativeSharp mínimos para construir metadata y headers C sin duplicar Frontend;
- streams y filesystem temporal aislado para truncamiento, publicación atómica y directorios;
- oráculos estructurales independientes para payload, SHA-256, API, ABI, C y reportes;
- un ejecutable unitario consolidado y fixtures `.ns` externos en la fase 2.

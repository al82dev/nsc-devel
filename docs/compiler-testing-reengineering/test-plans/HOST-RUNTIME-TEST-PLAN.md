# Plan de pruebas — Host.Runtime

## 1. Alcance

Plan contractual de 48 contratos y 384 casos diseñados. No implementa ni ejecuta pruebas.

## 2. Fixtures futuros

- builders de IR mínimo para catálogo ABI, símbolos, globals y particiones de imagen;
- inspección estructural LLVM independiente de nombres de helpers internos;
- adaptadores Win32 controlados para paths, handles, buffers, procesos y sincronización;
- programas `.ns` mínimos para confirmar cada wrapper de punta a punta;
- ejecución real Win32 separada de unitarias deterministas de IR y contrato.

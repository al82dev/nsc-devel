# Plan de pruebas — Host.Target

## 1. Alcance

Plan contractual de 30 contratos y 240 casos diseñados. No implementa ni ejecuta pruebas.

## 2. Fixtures futuros

- oráculo entero independiente para alineación, overflow, arrays y agregados;
- matrices x64/ARM64, tipos builtin, pack, offsets, unions, flexible arrays y bit-fields;
- tabla completa de niveles CPU, features, registros y mnemónicos;
- comparación exacta de cada layout, string y veredicto, sin invocar LLVM.

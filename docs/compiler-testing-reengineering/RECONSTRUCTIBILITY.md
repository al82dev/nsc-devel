# Estado de reconstructibilidad

Ningún componente está cerrado todavía. Todos comienzan como `NO VERIFICADO` y sólo pueden llegar a
`RECONSTRUIBLE` después de responder las veinte preguntas normativas, cerrar su matriz de contratos y superar
una segunda auditoría independiente.

El estado canónico por componente se conserva en `inventory/components.csv`. Este documento no sustituye esa
tabla; registra el criterio y enlazará los informes individuales conforme se produzcan.

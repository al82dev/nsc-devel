# Documentación de NativeSharp

La entrada vigente es [Contrato vigente de trabajo y consulta](CONTRATO-VIGENTE.md).
Se utiliza la instalación congelada `C:\native-sharp`. Hay un solo lenguaje acumulativo y un solo
contrato público vigente. No se elige una edición por el banner de `nsc --version`.

## Archivo de etapas anteriores

- [Etapa 2.0](2.0/README.md) — documentación histórica; no selecciona otro compilador.
- [Etapa 1.0.1](1.0.1/README.md) — documentación histórica; no ordena una migración actual.

Las carpetas `3.0` y `3.0.4` también contienen expedientes de sus etapas. Sus instrucciones antiguas
no autorizan cambiar la instalación. Los expedientes retirados de consulta activa se preservan en
`A:\native-sharp-documentation-history\2026-11-06`, con hashes y procedencia.

Los expedientes bajo `mkdown/` pertenecen al repositorio de desarrollo y conservan la historia de
ingeniería. No se copian aquí porque esta carpeta contiene documentación de producto, no el diario
de implementación.

# NativeSharp documentation

Read [the current working contract](CONTRATO-VIGENTE.md) first. Use the frozen installation at
`C:\native-sharp`. NativeSharp has one cumulative language and one current public contract.
Version-named directories preserve engineering history; they do not select alternative compilers,
dialects, or ABIs and do not authorize migration or reinstallation.

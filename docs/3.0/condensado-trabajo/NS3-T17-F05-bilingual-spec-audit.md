# NS3-T17-F05 — Auditoría de especificación bilingüe / Bilingual specification audit

## Español

Cada cláusula normativa comparte un ID estable entre español e inglés y debe conservar paridad de requisitos, ejemplos y notas de compatibilidad. La auditoría también exige glosario consistente, enlaces válidos, muestras compilables y presencia en los índices finales; una página huérfana bloquea el cierre.

## English

Every normative clause shares one stable ID between Spanish and English and must preserve parity for requirements, examples, and compatibility notes. The audit also requires a consistent glossary, valid links, compilable samples, and inclusion in the final indexes; an orphan page blocks closure.

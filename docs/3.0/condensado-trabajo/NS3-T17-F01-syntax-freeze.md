# NS3-T17-F01 — Congelamiento de sintaxis / Syntax freeze

## Español

El candidato de congelamiento registra revisiones y hashes independientes de gramática, precedencia, palabras reservadas y recuperación. La gramática de referencia debe generarse desde una fuente canónica. El validador falla si falta evidencia del corpus parser, análisis de ambigüedad, round-trip del formatter o snippets de la especificación. Este contrato prepara el freeze; no afirma que el baseline externo haya sido certificado.

## English

The freeze candidate records independent revisions and hashes for grammar, precedence, reserved words, and recovery. The reference grammar must be generated from one canonical source. Validation fails without parser-corpus, ambiguity-analysis, formatter round-trip, or specification-snippet evidence. This contract prepares the freeze; it does not claim that the external baseline has been certified.

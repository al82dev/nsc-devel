# NS3-T17-F03 — Congelamiento ABI Win64 / Win64 ABI freeze

## Español

El manifiesto normativo está restringido a Windows x64 y versiona mangling, layout, calling conventions, variants, trait objects, errores, coroutines públicas y metadata de módulo. No puede cerrarse sin fixtures DLL preservados, consumidor cross-version, snapshots de símbolos y contrato PDB. El validador prepara el candidato; no reemplaza la certificación externa.

## English

The normative manifest is restricted to Windows x64 and versions mangling, layout, calling conventions, variants, trait objects, errors, public coroutines, and module metadata. It cannot close without preserved DLL fixtures, a cross-version consumer, symbol snapshots, and the PDB contract. The validator prepares the candidate; it does not replace external certification.

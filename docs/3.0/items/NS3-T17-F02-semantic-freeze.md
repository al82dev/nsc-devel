# NS3-T17-F02 — Congelamiento semántico / Semantic freeze

## Español

El manifiesto congela revisiones independientes de overloads, conversiones, inference, ownership/drop, errores, async y memory model. Las excepciones sólo pueden apuntar a hitos posteriores a 3.0. La validación exige evidencia normativa y determinismo entre configuraciones; prepara un candidato y no sustituye el baseline externo.

## English

The manifest freezes independent revisions for overloads, conversions, inference, ownership/drop, errors, async, and the memory model. Exceptions may only target post-3.0 milestones. Validation requires normative evidence and cross-configuration determinism; it prepares a candidate and does not replace the external baseline.

# NS3-T17-F06 — Candidatos de lanzamiento / Release candidates

## Español

Cada RC identifica y hashea el feature set y los known issues. RC1 no acepta features nuevas, RC2 sólo fixes/bloqueadores y RC3 únicamente bloqueadores de promoción. Cualquier cambio reinicia los gates afectados. El candidato permanece inválido hasta registrar matriz limpia, upgrade/downgrade de metadata, reproducibilidad, stress prolongado y ejemplos sin paquete.

## English

Every RC identifies and hashes its feature set and known issues. RC1 accepts no new features, RC2 accepts only fixes/blockers, and RC3 accepts promotion blockers only. Every change restarts the affected gates. A candidate remains invalid until it records a clean matrix, metadata upgrade/downgrade, reproducibility, long-running stress, and package-free samples.

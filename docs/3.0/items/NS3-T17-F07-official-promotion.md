# NS3-T17-F07 — Promoción oficial / Official promotion

## Español

La promoción oficial es fail-closed. Además del baseline externo y la conformidad Debug/Release, requiere cero P0/P1 sin waiver, paridad bilingüe, migración validada, reproducibilidad, hashes del feature set/spec/suite, rama de mantenimiento `v.3.0`, frontera explícita para features experimentales, instalación Win64 de referencia, smoke interop, samples y artefactos verificados. Esta implementación entrega el mecanismo; no ejecuta ni declara la promoción.

## English

Official promotion is fail-closed. In addition to the external baseline and Debug/Release conformance, it requires zero unwaived P0/P1 issues, bilingual parity, validated migration, reproducibility, feature-set/spec/suite hashes, the `v.3.0` maintenance branch, an explicit boundary for experimental features, a reference Win64 installation, smoke interop, samples, and verified artifacts. This implementation delivers the mechanism; it neither executes nor declares promotion.
